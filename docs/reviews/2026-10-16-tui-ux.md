# TUI clarity review

The version branch includes main at `2601eec`, including Logan's hash-column PR. This increment improves PR visibility and action discovery on top of the rebased workflow/status and stack-rename work.

## Changes

- Merged PRs use purple `⑂`, closed PRs red `×`, and approved PRs green `✓`, beside the PR number. Wide maps also show lifecycle names. Symbols remain distinct without color.
- Lookup suffixes distinguish not checked, checking, unavailable, and stale retained PR evidence. Details remain available below 120 columns through a popup.
- Opening details, `p`, and `R` explicitly refresh the selected PR, even in Archive or with status hidden. Requests capture branch and OID, bypass cached lookup results, and reset displaced checking states. Ordinary navigation still launches no provider work.
- `?` searches actions and runs the existing guarded handlers. Copy actions are available without Command chords. Delete remains uppercase `X` with confirmation.
- The header identifies Active/Archive. Archive feedback says Git branches are kept. `u` undoes the last single or range change after checking that branch state still permits it.
- The default footer focuses on common actions. Appearance and navigation commands remain in the menu. Search and execution controls remain visible in short terminals.

## Verification

Passed 312 library tests, 21 CLI unit tests, two doctests, formatting, strict offline all-target/all-feature Clippy, and diff checks. Render coverage includes 40, 80, 100, 140, and 200 columns, selected rows, no-color output, and a 40-by-8 action menu.

Independent review caught displaced lookups stuck in checking and feedback tied to cursor position. Both were repaired with regression coverage.

No standalone app build, installation, live authenticated PR lookup, terminal-process integration, or performance run was performed. The installed application still requires a separate build/install request to show these changes.
